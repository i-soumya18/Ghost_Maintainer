# The Ghost Maintainer 👻

> *"Voices are fiction. Evidence is real."*

A verifiable, local AI codebase archaeology tool answering questions about abandoned git repositories in the collective voice of departed maintainers ("we"), strictly enforcing commit-hash citations or refusing with *"The dead do not remember."*

## Overview

- **Read-Only Archaeology**: Never modifies target repositories; streams `git log` with field-weighted BM25 indexing.
- **Honesty Defense-in-Depth**: Retrieval gating, hallucination verification, and guarded remediation loops.
- **Multi-Paradigm Interface**: Typer CLI, FastAPI SSE server, and candlelit web archive UI.
